# DFMS Mission Control Prototype

DFMS (Drone Fleet Management System) is an INFO 380 class project focused on wind turbine maintenance operations.

This repository contains a **static frontend prototype** for the **DFMS Mission Control** screen, centered on the **Drone Inspection Dispatch Grid**. The product direction and requirements are defined in the project PRD.

## PRD Source of Truth

- Product Requirements Document (PRD): [`dfms_prd.md`](./dfms_prd.md)

## Prototype Scope

- Static HTML/CSS/JavaScript only (no backend).
- Uses static sample data only.
- No real drone dispatch, weather, HRIS, vendor, or map integrations.
- External products are design references only.
- Do not include third-party logos or proprietary assets.

## Run Locally

1. Open `prototype/index.html` directly in a browser.
2. No build step or package installation is required.
